Authorization helper:

public void requirePermission(AuthenticatedUser user, Permission permission) {
    if (!user.permissions().contains(permission.name())) {
        throw new ResponseStatusException(HttpStatus.FORBIDDEN, "Missing permission: " + permission);
    }
}

If current AuthenticatedUser only has roles, map roles to permissions in one place.

Add malware scanning interface even if implementation is no-op dev-only:

public interface MalwareScanner {
    MalwareScanResult scan(Path file);
}

public record MalwareScanResult(boolean clean, String scanner, String detail) {
    public static MalwareScanResult cleanDevBypass() {
        return new MalwareScanResult(true, "dev-bypass", "No scanner configured in local dev");
    }
}

Production rule:

If active profile is production and scanner is not configured, upload must be blocked or deployment must fail.
CORS

Production must not allow *.

Config stub:

@Configuration
public class CorsConfig {
    @Bean
    CorsConfigurationSource corsConfigurationSource(EvidaSecurityProperties properties) {
        CorsConfiguration config = new CorsConfiguration();
        config.setAllowedOrigins(properties.getAllowedOrigins());
        config.setAllowedMethods(List.of("GET", "POST", "PUT", "DELETE", "OPTIONS"));
        config.setAllowedHeaders(List.of("Authorization", "Content-Type", "X-Evida-Tenant-ID", "X-Evida-Case-ID"));
        config.setAllowCredentials(true);

        UrlBasedCorsConfigurationSource source = new UrlBasedCorsConfigurationSource();
        source.registerCorsConfiguration("/api/**", config);
        return source;
    }
}
Security headers

Add via Spring Security if configured:

http.headers(headers -> headers
    .contentSecurityPolicy(csp -> csp.policyDirectives("default-src 'self'; frame-ancestors 'none'"))
    .frameOptions(frame -> frame.deny())
    .contentTypeOptions(withDefaults())
);

Adapt to Spring Security version.
