# EVIDA — databehandleravtale / DPA (utkast)

Behandlingsansvarlig og databehandler fylles inn før signering. Behandlingen er begrenset til dokumentinntak, malwarekontroll, OCR/parsing, kildeindeksering, kildebundet analyse, eksport, audit, backup og sletting etter dokumenterte instrukser.

Datakategorier kan omfatte saksdokumenter og identifikasjonsopplysninger. Registrerte kan være klienter, motparter, vitner og andre omtalte. Tilgang gis bare inviterte brukere med minste privilegium. Data skal lagres i avtalt EØS-lokasjon, kryptert i transport og på lagringsvolum.

Underleverandører krever forhåndsgodkjent liste og datalokalitet. Eksterne AI-kall er deaktivert med mindre separat provider, region, retention og DPA er godkjent. Avvik varsles uten ugrunnet opphold. Ved opphør slettes eller returneres data etter skriftlig instruks, med dokumentert backup-utløp.
