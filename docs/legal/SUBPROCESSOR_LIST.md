# Underleverandører / subprocessors

Status før pilot:

| Leverandør | Formål | Data/region | Status |
|---|---|---|---|
| Pilotens avtalte VPS-/hostingoperatør | Compute, database, kryptert lagring og backup | Må fylles inn, EØS kreves | Ikke valgt/godkjent |
| Pilotens OIDC/IdP | Identitet, MFA og tilgang | Må fylles inn | Ikke valgt/godkjent |
| Ekstern AI-provider | Ingen i standard pilot; provider-kall er deaktivert | Ingen overføring | Deaktivert |

Ny leverandør krever sikkerhetsvurdering, datalokasjon, retention, DPA og skriftlig godkjenning før data sendes.
