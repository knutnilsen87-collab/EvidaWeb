# Behandlingsprotokoll — EVIDA-pilot

| Felt | Registrering |
|---|---|
| Formål | Sikker behandling og kildebundet analyse av én pilotsak |
| Kategorier registrerte | Klient, motpart, vitne, saksaktører |
| Datakategorier | Dokumentinnhold, metadata, bruker-/tilgangsdata, audit |
| Mottakere | Inviterte pilotbrukere og godkjente subprocessors |
| Overføring utenfor EØS | Nei som standard; krever separat godkjenning |
| Retention | Se `docs/operations/DATA_RETENTION_AND_DELETION.md` |
| Tiltak | OIDC/JWT, RBAC, tenantfilter, HTTPS, malwarekontroll, backup, audit |
| Eier | Behandlingsansvarlig oppgitt i signert pilotavtale |

Protokollen skal oppdateres ved ny provider, ny datalokasjon, nytt formål eller endret retention.
